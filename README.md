# ShopZone — Simple E-commerce Store
Frontend: HTML, CSS, JavaScript | Backend: Express.js | Database: SQLite (built into Node 22+)

## Setup
1. Install Node.js LTS (nodejs.org)
2. Open this folder in a terminal
3. Run: npm install
4. Run: npm start
5. Open http://localhost:3000

Product images live in public/img/ (product1.jpg ... product8.jpg, hero.jpg)
